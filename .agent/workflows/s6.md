TUGAS S6. Dasar: docs/FASE2_PLAN.md. JANGAN mengubah firestore.rules. JANGAN membuat unggah
sumber (S7) atau Sumber Saya (S8).

1. lib/providers/provider_admin_provider.dart sebagai ChangeNotifierProxyProvider<AuthProvider,
   ProviderAdminProvider> dengan syncUser(uid, {isAdmin}) (hanya admin melanggan). Menyimpan
   pending (ProviderService.watchPending), providers (fetchProviders, dimuat ulang setelah
   tiap tindakan), busy, error. Method review(uid, {approve, note}), terminate(uid, reason),
   reactivate(uid), reload(). Tangkap ProviderException dan pakai pesannya; untuk terminate
   tampilkan berapa sumber belum ditangguhkan bila ada. Daftarkan di appProviders.
2. lib/screens/admin_screen.dart: tab ketiga 'Penyedia' (DefaultTabController length 3), label
   'Penyedia (n)' dari jumlah pengajuan pending, seperti tab Laporan.
3. Bagian 'Pengajuan': kartu per pengajuan pending (nama usaha, telepon, deskripsi, waktu).
   Ketuk -> lembar tinjau dengan data lengkap, Setujui dan Tolak. Tolak wajib catatan >= 5
   karakter (validateAdminNote), maksimal 200. Loading dan galat ditangani; setelah berhasil
   lembar menutup dan daftar berubah. Kosong: 'Tidak ada pengajuan yang menunggu'.
4. Bagian 'Penyedia': daftar active dan terminated (chip status) dengan jumlah sumber
   (SourceProvider.all per ownerId). 'Putuskan kemitraan' (active): dialog alasan wajib, jelaskan
   semua sumbernya ditangguhkan, tampilkan hasilnya. 'Aktifkan kembali' (terminated): dialog
   yang menyatakan sumber ditangguhkan TIDAK otomatis tayang lagi dan harus ditayangkan satu
   per satu.
5. Sembunyikan tindakan pada pengguna ber-role admin (admin tidak bisa memutus admin).
6. Tes: ProviderAdminProvider (stream pending, review setuju/tolak memperbarui daftar, tolak
   tanpa catatan ditolak, urutan terminate, galat dipetakan, reset saat ganti pengguna,
   non-admin tidak melanggan); widget test tab Penyedia.
7. Jalankan /cek. Perbarui status S6 di docs/FASE2_PLAN.md.
